# 运行本地模型

本文从 PowerShell 构建纯 C# 引擎，并在本机运行 Granite 模型或 HTTP 服务。需要 .NET 10 SDK 和仓库同级 `models` 目录中的 `granite-3.1-1b-a400m-instruct-Q4_K_M.gguf` 文件。

## 构建与验证

从仓库根目录打开第一个 PowerShell 窗口后执行：

```powershell
Set-Location .\src
dotnet build LlmStupid.sln -c Release
```

构建成功时，四个项目均显示 `已成功生成`，错误和警告为 0。用目标 GGUF 运行定向验证：

```powershell
$model = [System.IO.Path]::GetFullPath((Join-Path (Get-Location) '..\..\models\granite-3.1-1b-a400m-instruct-Q4_K_M.gguf'))
if (!(Test-Path -LiteralPath $model)) { throw 'Granite GGUF is missing from the sibling models directory.' }
dotnet run --no-build --project .\LlmStupid.Verification -c Release -- $model
```

成功时输出 `Verification passed`，并报告量化核、GGUF、tokenizer 和单 token 推理检查通过。

## 命令行生成

在 `src` 目录运行：

```powershell
$model = [System.IO.Path]::GetFullPath((Join-Path (Get-Location) '..\..\models\granite-3.1-1b-a400m-instruct-Q4_K_M.gguf'))
dotnet run --no-build --project .\LlmStupid.Tool -c Release -- generate $model --prompt 'Say hello.' --tokens 10 --threads 10 --context 256 --temperature 0
```

终端先显示生成文本，再分别显示模型加载、提示词处理、首 token、生成速度和工作集。此命令不启动服务。

## 启动 HTTP 服务

在第一个 PowerShell 窗口的 `src` 目录启动服务：

```powershell
$env:LLM_MODEL_PATH = [System.IO.Path]::GetFullPath((Join-Path (Get-Location) '..\..\models\granite-3.1-1b-a400m-instruct-Q4_K_M.gguf'))
$env:LLM_THREADS = '10'
$listenUrl = 'http' + '://127.0.0.1:5089'
dotnet run --no-build --no-launch-profile --project .\LlmStupid.Service -c Release --urls $listenUrl
```

日志显示服务已监听本机 `5089` 端口后，用第二个 PowerShell 窗口请求：

```powershell
$baseUrl = 'http' + '://127.0.0.1:5089'
$models = Invoke-RestMethod "$baseUrl/v1/models"
$request = @{ model = $models.data[0].id; messages = @(@{ role = 'user'; content = 'Say hello.' }); max_tokens = 10; temperature = 0; stream = $false } | ConvertTo-Json -Depth 6
$answer = Invoke-RestMethod "$baseUrl/v1/chat/completions" -Method Post -ContentType 'application/json' -Body $request
$answer.choices[0].message.content
```

响应中的 `choices[0].message.content` 是生成文本；`usage` 和 `local_metrics` 提供 token 数、延迟、生成速度及工作集。`/health` 用于检查服务状态。服务支持 `stream = $true` 的 SSE 响应；设为 `true` 后请求返回逐块 `data:` 事件并以 `data: [DONE]` 结束。按 Ctrl+C 停止服务。
