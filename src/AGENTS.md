# C# 源码根入口

本目录是 llm-stupid 唯一产品源码根。开始改动前读取 `../文档/项目/项目_llm-stupid/AGENTS.md` 与 `../文档/项目/项目_llm-stupid/当前设计.md`，并通过 `rg` 检查当前实现、公共类型和测试。

保留推理核心与宿主分离；性能优化必须落在可替换的托管 CPU backend 中，并与标量结果核对。新增依赖前确认不能由 .NET 10 BCL 完成；不加入 llama.cpp 或原生推理运行时。模型文件、构建产物和临时 benchmark output 均留在仓库外。

每个源码项目应有明确层次和职责；公共接口只表达引擎/服务消费边界，测试覆盖易错的格式、数值和状态行为。变更后运行目标项目 Release build 及针对改动的测试，不自动运行独立系统测试或部署。
